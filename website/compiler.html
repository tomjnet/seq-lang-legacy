The Compiler

seqc_legacy takes a main.seq file through every stage of a real compiler and writes a native executable. The stages talk only through their data: the assembler reads the text the code generator wrote, not its internal structures, and the linker reads only the object.

The eight stages

StageSourceWhat it does
Lexersrc/lexerSource text to tokens, one SourceLine per line
Parsersrc/parserTokens to the syntax tree
Semantic analysissrc/semaChecks the tree; matches each ask to a request and resolves the dataset and filter
IRsrc/irLowers requests to write_file and print operations on constant data; the filter is evaluated here
Code generatorsrc/codegenIR to x86-64 assembly text
Assemblersrc/assemblerAssembly text to machine code, symbols and relocations
Linkersrc/linkerLays out the sections, applies the relocations, writes the ELF file
Runsrc/driverExecutes the binary in output/
Compile-time evaluation. Because the filter is evaluated at compile time, the generated program only writes bytes that the compiler already computed.

Intermediate form

The IR is a list of named constant data blobs and, per step, a list of operations. This is top3Company.ir:

program top3Company
data d0 = "company.txt\0"
data d1 = 76 bytes  ; rows 1-5 of sample-company-transaction-db
data d2 = 82 bytes  ; top 3 of total-revenue-by-company
step 1 step1:
  write_file d0, d1
step 2 step2:
  print d2

Generated assembly

The generated program is _start, one function per step, and a failure exit. It calls the kernel directly (open, write, close, exit) and links against nothing. It exits 0, or 70 when a system call fails.

section .text
global _start
_start:
    call seq_step_1
    call seq_step_2
    xor edi, edi
    mov eax, 60            ; exit(0)
    syscall
seq_fail:
    mov edi, 70
    mov eax, 60            ; exit(70)
    syscall
seq_step_1:
    lea rdi, [rel d0]
    mov esi, 577           ; O_WRONLY | O_CREAT | O_TRUNC
    mov edx, 420           ; 0644
    mov eax, 2             ; open
    syscall
    test rax, rax
    js seq_fail
    mov rbx, rax
    mov rdi, rbx
    lea rsi, [rel d1]
    mov edx, 76
    mov eax, 1             ; write
    syscall
    test rax, rax
    js seq_fail
    mov rdi, rbx
    mov eax, 3             ; close
    syscall
    ret
seq_step_2:
    mov edi, 1
    lea rsi, [rel d2]
    mov edx, 82
    mov eax, 1             ; write
    syscall
    test rax, rax
    js seq_fail
    ret
section .rodata
d0:
    db "company.txt", 0
d1:
    db "ACME,10,25.50", 10, ...
d2:
    db "Top 3 total-revenue-by-company:", 10, ...

Encoding table

The assembler knows nine instructions. Only the registers rax rcx rdx rbx rsp rbp rsi rdi and their 32-bit forms are supported, so no REX.R or REX.B bits are needed.

InstructionEncodingExample
mov r32, imm32B8+r imm32mov eax, 60 = B8 3C 00 00 00
mov r64, r6448 89 /rmov rbx, rax = 48 89 C3
xor r32, r3231 /rxor edi, edi = 31 FF
test r64, r6448 85 /rtest rax, rax = 48 85 C0
lea r64, [rel sym]48 8D /r + disp32lea rdi, [rel d0] = 48 8D 3D disp32

retC3 
syscall0F 05 

Every symbol reference becomes a relocation; the assembler never resolves one itself. There is one relocation type, PC-relative 32-bit: the four bytes receive S + A - P, where S is the symbol address, P is the address of the field and A is the addend.

ELF layout

The linker writes one PT_LOAD segment, readable and executable, that maps the whole file.

ItemValue
Base address0x400000
ELF headeroffset 0, 64 bytes
Program headeroffset 64, 56 bytes, one entry
.textoffset 0x80
.rodataafter .text, aligned to 16
Header fieldsELFCLASS64, little endian, ET_EXEC, EM_X86_64, no section headers

Files it writes

output/ holds only what your program creates. Everything the compiler writes goes in output/temp/, so you can read what every stage produced.

top3Company/
|-- src/
|   `-- main.seq
`-- output/
    |-- company.txt             written by the program
    `-- temp/
        |-- top3Company.tokens  lexer output
        |-- top3Company.ast     parser output
        |-- top3Company.ir      intermediate representation
        |-- top3Company.asm     generated x86-64 assembly
        |-- top3Company.lst     assembler listing: offsets and bytes
        `-- top3Company.bin     the ELF executable
