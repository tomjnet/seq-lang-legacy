Requirements

Linux or WSL
A C++11 compiler
CMake 3.20 or newer
Ninja

Download & Build

Seq Legacy is distributed as source code. There are no binary packages: you build seqc_legacy yourself, which takes a few seconds.

What you need

seqc_legacy itself is a C++11 program built with CMake and Ninja; it uses nothing from a later standard and has no third-party dependencies. A host compiler (g++ or clang++) is needed only to build the compiler, never to compile a .seq file.

Windows users: the run stage executes a Linux binary, so build and test on Linux or in WSL.

Build

From the root of the source tree:

$ cmake --preset dev
$ cmake --build --preset dev
$ ctest --preset dev

The compiler is build/dev/seqc_legacy.

Install

The install script copies the compiler to /usr/local/bin. It uses sudo, so it will ask for your password.

$ bash install-seqc.sh

Your first project

$ seqc_legacy new top3Company
Seq Legacy Compiler

Creating project: top3Company

[create] top3Company/
[create] top3Company/src/
[create] top3Company/src/main.seq
[create] top3Company/output/

Target: Linux x86_64

Project created successfully.

Next:
  cd top3Company
  seqc_legacy src/main.seq

Then do what it says:

$ cd top3Company
$ seqc_legacy src/main.seq

The source file must be <project>/src/main.seq. Each build overwrites the previous artifacts and outputs. Now go and read about the language, or see how the compiler works.
