Welcome to Seq Legacy

seqc_legacy is a proof-of-concept compiler for a small subset of the Seq language. It turns main.seq into a static Linux x86-64 executable using only its own code: its own code generator, its own assembler and its own linker.

Nothing else is started. The whole build and run succeed with an empty PATH. There is no language model, no GCC, no external assembler and no external linker anywhere in the pipeline.

A first program

A Seq program has a name and one or more steps. Each step asks for something to be done. This is src/main.seq, the file that seqc_legacy new top3Company writes for you:

name = "top3Company"

step step1():
    ask("create file company.txt with 5 sample-company-transaction-db")

step step2():
    ask("for-each transaction get 3 top total-revenue-by-company")

Compile and run it:

$ seqc_legacy src/main.seq

Change 5 to 10 and company.txt gets ten rows; change 3 to 2 and two companies are printed. Read more about the language »

seqc_legacy --build-only <file.seq>Stop after the linker

seqc_legacy --help, --versionUsage, version

Exit codes: 0 success, 1 internal error, 2 usage, 3 source error, 6 the program failed, 7 filesystem.

Limits of the proof of concept

  • Linux x86-64 only. On other systems seqc_legacy still builds and --build-only still writes the ELF file, but it cannot run it.
  • The assembler knows nine instructions and the eight low registers. See the encoding table.
  • The executable is one read-and-execute segment with no section headers, so objdump -d shows nothing; read output/temp/<name>.lst instead.
