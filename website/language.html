The Language

The legacy subset of Seq is deliberately tiny. A source file declares a program name, then one or more steps, and every step contains one or more ask statements.

Grammar

file      := name_decl step+
name_decl := "name" "=" STRING
step      := "step" IDENT "(" ")" ":" NEWLINE
             ( 4 spaces "ask" "(" STRING ")" NEWLINE )+

Lexical rules

RuleContract
Keywordsname, step and ask are identifiers compared by text, not separate tokens
IndentationExactly 0 spaces (declaration, step header) or 4 spaces (ask); tabs are an error
StringsDouble-quoted, single line, escapes \" \\ \n \t
Comments# to end of line, except inside a string
EncodingUTF-8; one BOM skipped; CRLF read as LF
Name[A-Za-z_][A-Za-z0-9_-]*, at most 64 characters
LimitsSource 1 MiB, prompt 4096 bytes, 64 steps, 16 asks per step

Requests

The text of an ask is split on single spaces and must match one of two patterns exactly. Only the parts in angle brackets may vary.

RequestMeaning
create file <file> with <N> <dataset>Write the first N rows of the dataset to output/<file>
for-each transaction get <N> top <filter>Apply the filter to the rows of the most recent file and print the top N
PartRule
<file>[A-Za-z0-9_][A-Za-z0-9_.-]*, at most 64 characters, no path separators
<N> in create fileDecimal, 1 to the number of rows in the dataset (500)
<N> in for-eachDecimal, 1 to 100; if N is larger than the number of companies, all companies are printed
<dataset>Name of a built-in dataset
<filter>Name of a built-in filter

Built-in dataset: sample-company-transaction-db

500 rows of company,quantity,price, embedded into the compiler when it is built. There is no header, and there are ten companies: ACME, Globex, Initech, Umbrella, Hooli, Stark, Wayne, Wonka, Cyberdyne and Soylent. The first ten rows are:

Built-in filter: total-revenue-by-company

The revenue of a company is the sum of quantity × price over its rows, highest first. Equal revenue keeps first-appearance order. The arithmetic is done in integer cents; there is no floating point.

Error messages

The compiler points at the place it did not understand, and one run reports every error it finds in the file:

src/main.seq:4:9: error[E0401]: unrecognized request
        ask("make me a sandwich")
            ^
    hint: supported: create file <file> with <N> <dataset>
seqc_legacy: 1 error(s) in src/main.seq
CodeMeaning
E0401Request matches no known pattern
E0402Unknown dataset
E0403Unknown filter
E0404Count is not a number or is out of range
E0405Invalid file name
E0406for-each request with no earlier create file request
E0407model(...) or backend.X() is not supported in seqc_legacy
